# Roadmap

## v1.0 — competition archival release

- [x] Curated firmware and original hardware sources
- [x] 30 BOARD / 28 logical-model evidence boundary
- [x] 170 HOST asset contracts and fail-closed board receipt
- [x] Bilingual documentation and privacy-clean competition media
- [x] License matrix, release verifier, CI and security policy

## v1.1 — reproduction kit

- [ ] Publish signed Release manifests for the large model/evidence archive
- [ ] Add containerized host-smoke dependencies where licenses permit
- [ ] Add a hardware-in-the-loop CI recipe that users run on their own board
- [ ] Replace excluded OV5640 table with a clean, permissively licensed port
- [ ] Regenerate the CJK bitmap from an OFL font and verify glyph coverage

## v1.2 — community ports

- [ ] Document additional GD32 targets without weakening the truth ledgers
- [ ] Add calibration recipes for alternative sensors
- [ ] Accept new material task contracts with prospective blind evaluation

## Research directions, not promises

- Real-furnace validation with independent safety engineering
- Prospective blind tests on enterprise IC-material data
- Long-duration EMC, thermal and storage qualification

## Non-goals

Cloud dependence, AI direct actuation, representing HOST assets as BOARD,
representing phosphor chemistry as all IC materials, or claiming industrial
certification without independent evidence.
