Lab-Sentinel public firmware snapshot
=====================================

Open project/CIMC_GD32_Template.uvprojx and select target
CIMC_GD32_Template.  This public snapshot uses an explicit camera-disabled
OV5640 adapter and an ASCII font fallback because the original camera register
table and Windows-derived CJK bitmap cannot be redistributed.

See ../../docs/03-firmware/build-keil-r21.md before building or flashing.
