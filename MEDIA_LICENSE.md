# Media licensing and privacy

Unless a file contains a more specific notice, project-created diagrams and
documentation screenshots under `assets/` are licensed CC-BY-4.0.

Competition photographs are provided as privacy-clean public derivatives:
embedded metadata and location coordinates are removed, and visible name
badges, barcodes or other identifiers are redacted. Portrait and publicity
rights remain with the depicted people; the repository license does **not**
grant a right to use a person's likeness for advertising or model training.
The identifiable team portrait is withheld from the public repository until
every depicted person has documented publication consent.

The long demonstration video is not stored in Git history. Sanitized chapters
are attached to the GitHub Release; the original phone recording is withheld
because it contained device and precise-location metadata. See
`docs/08-demo/video-chapters.md`.

Competition organizer and corporate logos are excluded from the project media
license. See `TRADEMARKS.md`.
