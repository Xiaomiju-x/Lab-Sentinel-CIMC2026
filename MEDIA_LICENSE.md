# Media licensing and privacy

Unless a file contains a more specific notice, project-created diagrams and
documentation screenshots under `assets/` are licensed CC-BY-4.0.

Competition photographs are provided as privacy-clean public derivatives:
embedded metadata and location coordinates are removed, and visible name
badges, barcodes or other identifiers are redacted. Portrait and publicity
rights remain with the depicted people; the repository license does **not**
grant a right to use a person's likeness for advertising or model training.
At the project maintainer's explicit direction, the team portrait is published
as an archival project record after badge-name and barcode redaction. This
publication does not grant downstream publicity, biometric-analysis or model-
training rights. A depicted person may request removal through the repository's
private vulnerability-reporting channel.

The long demonstration video is not stored in Git history. The v1.0.2 Release
contains a content-complete continuous derivative plus five sanitized chapters.
At the project maintainer's explicit archival direction, the same Release also
contains `lab-sentinel-original-media-sources-privacy-sensitive-v1.0.2.zip`,
which preserves the exact seven originally supplied source files. That ZIP may
retain device/precise-location metadata, identifiable faces, badge contents and
visible time/location overlays. It is an archive-only provenance object: it is
not covered by the general CC-BY media grant and grants no advertising,
biometric-analysis, model-training or downstream publicity rights. See
`docs/08-demo/video-chapters.md` and the ZIP's `README_FIRST.md`.

Competition organizer and corporate logos are excluded from the project media
license. See `TRADEMARKS.md`.
