# Five-minute demo route

1. **0:00–0:45 — identity and truth ledgers:** project, awards, 30/28 BOARD and
   170 HOST boundary.
2. **0:45–1:30 — process/HMI:** deterministic profile, local state and data
   freshness; explicitly call the 1500 °C curve a replay.
3. **1:30–2:30 — hardware:** controller/PCB, point and field temperature,
   environment, electrical, vibration, camera, low-voltage actuators.
4. **2:30–3:30 — vision/PL:** live/fallback camera source label and historical
   PL replay; no online-spectrometer claim.
5. **3:30–4:25 — models:** AI-12 board timing, nano-LM task boundary, P096
   HOST–EXACT example.
6. **4:25–5:06 — interaction/safety:** fixed voice, touch, deterministic stop,
   authority=0 and evidence closeout.

Always demonstrate observable facts before architecture promises. If a sensor
channel is not fresh, say so and show the missing-source behavior.
