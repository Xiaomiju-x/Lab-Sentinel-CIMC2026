# Minimum model card schema

Every contributed model should answer:

```yaml
model_id: unique logical identity
task: decision and output semantics
ledger: BOARD | HOST-EXACT | HOST-SIM_ONLY
authority: 0
input:
  modality: ...
  shape: ...
data:
  source: ...
  license: ...
  label_definition: ...
  split_unit: batch/family/document/...
  leakage_checks: ...
baseline:
  metric: ...
  value: ...
training:
  seeds: [...]
  selection_rule: ...
deployment:
  quantization: ...
  runtime: ...
  memory: ...
evidence:
  golden_sha256: ...
  package_sha256: ...
limitations:
  - ...
failure_and_refusal:
  - ...
```

Checkpoints, seeds, prompts and quantization copies inherit the logical ID and
must not inflate model count.
