# Responsible use

Good uses include education, MCU optimization research, model/data governance,
low-voltage laboratory prototypes and reproducible materials-informatics task
design.

Before any industrial adaptation:

- obtain lawful, representative prospective data;
- repeat calibration and blind evaluation for the actual sensor/material;
- perform independent hazard analysis, functional-safety design and EMC tests;
- separate safety-rated hardware from experimental software;
- provide emergency stop, current/temperature limits and trained supervision;
- verify privacy, cybersecurity, maintenance and rollback.

Do not use this repository to make autonomous high-temperature decisions,
medical/safety claims, or production-quality guarantees. Do not erase rejected
receipts merely because they are inconvenient.
