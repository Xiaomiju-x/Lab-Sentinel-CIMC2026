# Provenance

The provenance chain records:

1. immutable source identifier and retrieval/measurement context;
2. license or permission;
3. checksum and byte count where redistributable;
4. label definition and who/what produced it;
5. truth class (`TEAM_MEASURED`, public experiment, public computation,
   simulation, fixture, teacher candidate, metadata);
6. split unit and overlap checks;
7. preprocessing fit scope;
8. task contract and output semantics.

If any required field is missing, the asset does not become EXACT merely
because a training script can run. Rejected tasks remain visible in
`pre_gpu_disposition_244.v1.json`.
