# Data licensing workflow

1. Identify the exact upstream record, version and license.
2. Verify that redistribution—not just access—is permitted.
3. Preserve attribution and any share-alike/non-commercial limits.
4. If rights are unclear, publish only a source locator/download script and
   checksum.
5. Never apply Apache-2.0 to third-party data by placing it beside code.
6. Record media/portrait permission separately from dataset copyright.

Europe PMC documents are admitted per-document, not by assuming that an entire
search result shares one license. Competition logos and templates are not
project-owned media.
