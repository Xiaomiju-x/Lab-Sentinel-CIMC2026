# Glossary

- **Asset** — a deployable or testable package. Multiple deployment sizes can
  implement one logical model.
- **Logical model** — a unique task/weight identity; seeds, checkpoints,
  prompts and quantized copies are not recounted.
- **BOARD** — executed on the GD32H759 frozen runtime with board evidence.
- **HOST–EXACT** — exact source/label/split binding and host acceptance; not
  board deployment.
- **HOST–SIM_ONLY** — simulation/interface research, not measured performance.
- **authority=0** — a model can predict, explain or advise but cannot directly
  actuate hardware.
- **Golden** — a frozen input/output fixture used to detect conversion/runtime
  drift; not a substitute for a held-out scientific test set.
- **Fail-closed** — missing or invalid evidence stops promotion/execution.
- **PSP** — process–structure–property relation. A graph edge is an auditable
  dependency or association, not automatically a causal claim.
- **REAL_DATA_REPLAY** — historical measured data replayed on the device; not
  live acquisition by the displayed instrument.
