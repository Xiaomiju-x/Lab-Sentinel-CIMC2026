# Data licenses and provenance

This repository does not apply the software license to datasets.

| Data class | Public release | Terms / boundary |
|---|---|---|
| 281 historical Fluoromax PL spectra | Metadata, contracts and selected fixtures only | Team/laboratory measured; redistribution is limited to files explicitly present here |
| 52 crucible photographs | Selected privacy-safe examples only | Project media terms; not a universal image-classification dataset |
| 67 material records, 37 with usable XRD phase labels | Schema/provenance only | Not “37 independent XRD spectra”; no unrestricted raw-data grant is implied |
| Carinthia SEM | Download/source contract only | Public external dataset; follow the upstream license and citation |
| SECOM | Source contract/download instructions | UCI dataset terms and citation apply |
| JARVIS / public computation | Manifest and download instructions | Public computational data, not team experimental ground truth |
| Europe PMC corpus | Per-document provenance only | Only source-bound CC-BY document families may be redistributed; paper text is not experimental truth |
| SIM_ONLY assets | Contracts and synthetic fixtures | Must not be represented as measured laboratory or production data |

Machine-readable provenance is under `data/provenance/` and `ai/contracts/`.
When a source license is uncertain, this release provides a locator, checksum or
download script instead of copying the data.
