# Hardware

`design/` contains the team-authored editable EDA project and manufacturing
exports for the integration/expansion PCB set. These files are licensed
CERN-OHL-S-2.0 unless an included file states otherwise.

See `docs/02-hardware/` for BOM, pin map, bring-up and safety boundaries. The
design is a low-voltage competition/research prototype, not a safety-certified
industrial controller.
