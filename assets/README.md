# Public media

- `hero/` and `diagrams/`: project-created SVG, CC-BY-4.0;
- `hardware/`: metadata-clean prototype/HMI derivatives;
- `competition/`: metadata-clean competition photographs; visible badges,
  barcodes and phone screens are redacted;
- `video/`: lightweight cover art only. Demonstration video chapters live in
  GitHub Releases.

Do not replace these files with raw phone media. The raw sources contained EXIF
and/or container location/device metadata. Portrait rights remain with the
people shown; see `MEDIA_LICENSE.md`.
